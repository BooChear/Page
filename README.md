# boochear — link page

## Перед деплоем

Положи в папку `media/` свои файлы (сейчас их там нет, в HTML/CSS на них только ссылки):

- `avatar.jpg` — аватар
- `wallpaper.jpg` — фон
- `favicon.svg` — уже добавлен, монограмма "B" (можно заменить своей)
- `twitch.svg`, `telegram.svg`, `youtube.svg`, `github.svg`, `donatty.svg` — иконки соцсетей

Названия файлов должны совпадать с теми, что указаны в `index.html`, либо поменяй пути в самом файле.

## Деплой на Vercel

### Вариант 1 — через сайт (без консоли)
1. Зайди на vercel.com и залогинься.
2. New Project → Add New → выбери "Deploy without Git" / перетащи папку `site` целиком (со всеми файлами и папкой `media`).
3. Framework Preset — выбери "Other" (это статический сайт, без сборки).
4. Deploy.

### Вариант 2 — через Vercel CLI
```bash
npm i -g vercel
cd site
vercel
```
Дальше просто следуй подсказкам в терминале (Enter почти везде подходит для статического сайта). Команда `vercel --prod` выкатит сразу в прод.

### Вариант 3 — через GitHub
1. Залей папку `site` в репозиторий на GitHub.
2. На vercel.com: New Project → Import Git Repository → выбери репозиторий.
3. Framework Preset — "Other", Build Command и Output Directory оставь пустыми.
4. Deploy.

## Что было оптимизировано

- Добавлены мета-теги (`description`, `theme-color`, Open Graph) — превью ссылки в Telegram/Discord теперь будет с картинкой и текстом.
- Подключён Google Fonts (Montserrat) — раньше шрифт был прописан в CSS, но нигде не загружался, поэтому браузер показывал системный шрифт вместо него.
- Добавлена SVG-иконка сайта (`favicon.svg`).
- Пути к файлам сделаны абсолютными (`/media/...`) — так они не сломаются при деплое на Vercel независимо от структуры роутинга.
- У картинок прописаны `width`/`height` — страница не "прыгает" при загрузке.
- Иконки соцсетей (кроме первой) грузятся с `loading="lazy"`.
- Ссылки открываются с `rel="noopener noreferrer"` — стандартная защита при `target="_blank"`.
- Повторяющиеся цвета в CSS (`#050505`, `#5a5a5a`, `#2e2e2e`) вынесены в переменные.
- Добавлен `focus-visible` — ссылки подсвечиваются и при навигации с клавиатуры, не только при наведении мышью.
- Добавлен `vercel.json` с кэшированием статики в `media/`.
